## בדיקות שבוצעו בפועל

- בניית `assembleDebug` הסתיימה בהצלחה. נוצר `app/build/outputs/apk/debug/app-debug.apk`, בגודל כ־19 MB.
- כל **14 בדיקות היחידה עברו**, ללא כשלונות או דילוגים. בין היתר נבדקו שעות בעברית, חצי שעה, זמנים עמומים, חיוג, ימי הולדת ויבוא טבלה.
- כל **6 בדיקות Android עברו** באמולטור Android 16, API 36. נבדקו מסך הבית וניווט לאנשי קשר, יבוא XLSX עם מחרוזות משותפות ופורמט טלפון, RSS/Atom, שחזור גיבוי ודחיית מידע לא תקין.
- `lintDebug` הסתיים עם **0 שגיאות ו־15 אזהרות**: המלצות לעדכון תלויות, שימוש ב־KTX והמלצה להגדיר גם `fullBackupContent` עבור Android ישן. `allowBackup=false` כבר מונע גיבוי בגרסאות הישנות; כללי הגיבוי החדשים מוגדרים בנפרד.
- APK אומת באמצעות `apksigner verify`: חתימת APK v2 תקינה, חותם יחיד. זהו מפתח **debug**, המיועד לניסוי בלבד; הוראות חתימה קבועה מופיעות במדריך ההתקנה.
- האפליקציה הותקנה והופעלה באמולטור. מסך הבית צולם ונבדק חזותית, ללא שגיאת AndroidRuntime של האפליקציה. בזמן האתחול הראשוני הופיעה באמולטור הודעת System UI שאינו מגיב; לאחר סגירת ההודעה ההפעלה והבדיקות הסתיימו בהצלחה.
- הדמיות ששת המסכים נוצרו ונבדקו חזותית במצב בהיר וכהה, ונבדקה היעדר גלישה אופקית במסגרת כל טלפון.
- בוצעו מהמחשב קריאות חיות לחיפוש העיר חיפה ולתחזית Open-Meteo. אומתו שדות המיקום, אזור הזמן, מזג האוויר הנוכחי והתחזית היומית. זו בדיקת חוזה השירות מהמחשב, ולא בדיקת רשת בטלפון פיזי.

- איכות זיהוי עברית ושמות, זמינות הקולות והעדפת קול גבר או אישה.
